핸드오프 파일을 읽어 이전 작업 맥락을 복원하고 오늘 작업 계획을 수립한다.

## 실행 순서

### 1. 01_handoff/ 폴더 확인
프로젝트 루트에 01_handoff/ 폴더가 없으면 생성한다.
폴더를 새로 만든 경우, 이전 기록이 없음을 안내하고 "새 프로젝트로 시작합니다." 라고 말한 뒤 종료한다.

### 2. 파일 읽기
다음 순서로 읽는다. 없는 파일은 건너뛴다:
1. 01_handoff/context.md — 중요 맥락·주의사항
2. 01_handoff/decisions.md — 주요 결정 사항
3. 01_handoff/progress.md — 완료된 작업 내역
4. 01_handoff/next-task.md — 다음 할 작업 (수동 메모)

### 3. 큐 미처리 항목 확인
아래 두 경로를 순서대로 확인한다. 폴더가 없으면 건너뛴다:

**01_handoff/queue/ready/ 확인:**
- `report_*.json` → 개발 세션 완료 보고서 (검토 대기)
- `next-task_*.json` → 미실행 지시서 (실행 대기)

**01_handoff/queue/approvals/ 확인:**
- `approval_*.json` → 미처리 결정 파일 (개발 세션이 아직 읽지 않은 것)

발견된 미처리 항목은 현황 보고에 포함한다.

### 4. 현황 보고
읽은 내용을 바탕으로 아래 형식으로 보고한다.
